Features

Read the docs

Agents & sessions

22 supported agents
Run Claude Code, Codex, Cursor, Gemini, and more with your existing CLI logins. Add custom agent definitions.
Projects, kept in order
Group chats by project. Pin, rename, reorder, and archive sessions without losing track of your work.
A real terminal
Use each agent’s own interface. Search output, quote selections, paste images, and open a shell beside your session.
Conversation history
Find and resume past Claude and Codex chats by title, project, or agent, including conversations started outside Diri.

Parallel work

Separate workspaces
Give each agent its own Git worktree so parallel tasks can change files on separate branches.
Handoffs & forks
Pass a task and its context to another agent. Fork conversations when the agent supports it.
Agents that coordinate
Through Diri’s MCP tools, agents can delegate tasks, follow progress, read output, and answer other agents’ prompts.
Remote machines
Start sessions on your own SSH hosts from the same workspace. Diri handles setup, with no hosted relay.

Review & follow-up

Status & notifications
See who’s working, waiting, or done. Get alerts and jump straight to the session that needs you.
Changes & commits
Inspect diffs, stage or discard changes, and commit from the workspace where the work happened.
Pull requests & links
Keep outputs and links beside their session, with pull request checks and discussion attached to the right PR.
Files & source code
Open file references from terminal output. Search local files and symbols, and inspect code without switching apps.

Usage & accounts

Cost & token usage
See estimated spend today and this month, token usage, and cache savings for Claude and Codex.
Context window
Check how much of the selected session’s context is used before deciding what to work on next.
Plan limits
Check Claude and Codex usage limits and reset times alongside your sessions.
Work & personal accounts
Choose a Claude or Codex account for each new session. Keep provider profiles and logins separate.

Your workspace

Commands & shortcuts
Find chats, open projects, and change settings from one command menu. Customize keyboard shortcuts to suit you.
Themes & type
Choose from built-in themes, preview your appearance, pick a terminal font, and adjust text size.
Skill library
Search personal, project, and plugin skills. Read their instructions, copy them, or open the source file.
Resource controls
Choose when to hibernate idle sessions and set a memory threshold for freezing idle agents.

On your devices

Sessions that stay open
Close and reopen Diri while local agents keep working. Return to the same session and terminal history.
iPhone companion Beta
Start sessions, send prompts, answer questions, and review changes over Tailscale while Diri is open on your Mac.
Native desktop app
A native macOS app, with a Linux beta. Install on macOS with a download or Homebrew.
Free & open source
No Diri account or subscription. Use your own agent accounts, on your computer or a host you control.
