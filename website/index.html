Features

Read the docs

Agents drive diri

Every tab, split, worktree and schedule is one of nearly 50 MCP tools. Ask Claude Code to start a Codex on your build server, put it beside you, wait for it and read back what it found.

Scheduled runs that wake your Mac

Start an agent every weekday at 7, every hour, or once tomorrow. diri wakes a sleeping Mac for the run, and a run missed while it was off still happens.

Computer use for every agent

Claude Code, Codex, Cursor and the rest can use your Mac’s apps in the background: the Simulator, Xcode, the app you are building. Your cursor and keyboard stay yours.

Talk while you do something else

When an agent finishes, diri reads you its summary. Answer out loud, end with “send to agent”, and it goes straight back to that agent.

Questions

More in the docs and guides.

Is diri free?

Yes. diri is free and open source under AGPL-3.0. You only pay for the agents you use, through your own Claude, ChatGPT or other accounts. If you distribute a modified copy, or let people use one over a network, you must offer them its source under the same license.

Which agents does it work with?

Claude Code, Codex, Cursor, Gemini, OpenCode, Pi, Copilot, Kimi and more: 22 agent definitions ship with the app, and any terminal agent can be added with a short JSON file.

Do I need to know how to code?

No. You describe tasks in plain English and the agents do the work. The guides are written for marketers and product managers as well as developers.

What happens when I close diri?

Your agents keep working. Reopen diri and every session is where you left it. Restarting your Mac stops them, but Claude Code, Codex and most others can resume the same conversation.

Can agents work together?

Yes. Agents started in diri can start other agents, on this Mac or on any of your SSH hosts, hand them tasks, wait for them, and collect their results. Ask in plain English, starting with “Use diri to…”.

Does diri see my code or prompts?

No. Agents run on your Mac or your own servers, with no diri account and no hosted relay. diri records crash and performance diagnostics, never terminal contents or prompts, and you can turn sharing off.

Which platforms are supported?

macOS 15 or newer on Apple silicon and Intel. Linux is in beta, and a Windows version is in progress.
