Questions

More in the docs and guides.

Is diri free?

Yes. diri is free and open source under AGPL-3.0. You only pay for the agents you use, through your own Claude, ChatGPT or other accounts.

Which agents does it work with?

Claude Code, Codex, Cursor, Gemini, OpenCode, Pi, Copilot, Kimi and more: 22 agent definitions ship with the app, and any terminal agent can be added with a short JSON file.

What happens when I close diri?

Your agents keep working. Reopen diri and every session is where you left it. Restarting your Mac stops them, but Claude Code, Codex and most others can resume the same conversation.

Can agents work together?

Yes. Agents started in diri can start other agents, on this Mac or on any of your SSH hosts, hand them tasks, wait for them, and collect their results. Ask in plain English, starting with “Use diri to…”.

Does diri see my code or prompts?

No. Agents run on your Mac or your own servers, with no diri account and no hosted relay. diri records crash and performance diagnostics, never terminal contents or prompts, and you can turn sharing off.

Which platforms are supported?

macOS 15 or newer on Apple silicon and Intel. Linux is in beta, and a Windows version is in progress.
