Review what changed

See every change an agent made before you keep it. Accept what you like, throw away what you do not, and ask the agent to check its own work.

6 min readEveryone · Git projects
On this page1. Open the Review panel2. Choose what to compare3. Keep or throw away4. Ask the agent to check itself5. Pull requests and checks
You will learn
  • How to see exactly what an agent changed
  • How to keep or throw away changes
  • How to ask the agent to check its own work

1Open the Review panel

Press ⇧⌘D to open the right panel and choose Review. It lists every file the agent changed in its folder, with the lines it added and removed.

This needs a Git project, the kind most software lives in. For any other folder the panel says Not a Git repository. You can still ask the agent directly:

Try saying

List every file you created or changed in this session, with one line on what changed in each.

2Choose what to compare

At the top of the panel, choose what you are looking at:

Default branch
Everything this session changed, committed or not. The best view of the whole piece of work.
HEAD
Only changes that are not committed yet.

3Keep or throw away

  • Stage all marks the current changes as the ones you want to keep.
  • Write a short message and click Commit to save them as one step in the project history.
  • Discard throws changes away. It asks once more before it does, because this cannot be undone.

4Ask the agent to check itself

In the Review panel, Ask active agent sends a ready-made request to the session's agent: Review, Find risks, or Suggest tests. You can also type your own follow-up.

5Pull requests and checks

If the agent opened a pull request, the link icon in the session header shows it with its checks: Passed, Failed or Running. Open it for the checks and discussion, or go straight to GitHub.

Prefer your own editor? In Settings → Appearance, set Open file links in to Cursor, VS Code, Zed or your default app.
