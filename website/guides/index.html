Learn diri in an afternoon

Short walkthroughs with real screens. You do not need to write code to follow them, unless a guide says it is for developers.

Start here

  1. 01Your first agentInstall diri, give an agent a task in plain English, and see what it made. About ten minutes.8 min · Everyone
  2. 02Never lose your workAgents keep working when you close diri. Here is what survives, what does not, and how to get any conversation back.6 min · Everyone

Work with many agents

  1. 03Run several agents at onceStart a second agent while the first one works, see every status at a glance, and give each task its own copy of the project.6 min · Everyone
  2. 04Let agents work as a teamAsk one agent to split a big job, start helpers, keep them on track and bring you the result. You just describe the goal.7 min · Everyone
  3. 05Review what changedSee every change an agent made before you keep it. Accept what you like, throw away what you do not, and ask the agent to check its own work.6 min · Everyone · Git projects

Go further

  1. 06Run agents on a scheduleHave an agent start at a set time, every weekday or just once tomorrow morning. Ask for it in plain words, and it runs even if the Mac was asleep.7 min · Everyone
  2. 07Run agents on your own serverRun agents on a machine you reach over SSH, from the same diri window, and know what survives a dropped connection.7 min · Developers
  3. 08Shortcuts worth learningEight shortcuts cover almost everything. The rest are here when you want them.3 min · Everyone
