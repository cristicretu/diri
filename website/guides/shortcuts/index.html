Shortcuts worth learning

Eight shortcuts cover almost everything. The rest are here when you want them.

3 min readEveryone
On this page1. The essentials2. Sessions3. Workspace4. Inside a session5. Find the rest
You will learn
  • The eight shortcuts that cover most days
  • Where to find and change every shortcut

1The essentials

⌘T
Start your default agent
⌘N
New session
⌘K
Search sessions or run any command
⇧⌘J
Jump to the next session that needs you
⇧⌘H
Search past conversations
⇧⌘I
Notifications
⌘1–⌘9
Switch to a session
⌘R
Rename the session

2Sessions

⌥⌘T
New Terminal
⌥⇧⌘N
New Codex session
⌘W
Close the session
⇧⌘T
Reopen a closed session
⌥⇧⌘W
Archive the session
⌘[ ⌘]
Previous or next session

3Workspace

⌘P
Open a project
⇧⌘D
Right panel: Review, Files, Browser
⌘J
A terminal under the session
⌘D
Split right
⌘B
Show or hide the sidebar
⌘,
Settings

4Inside a session

⌘F
Find in the output
⌘E
Insert a file path
⌘+ ⌘−
Bigger or smaller text
⇧⌘C
Quote the selection in your reply

5Find the rest

Hold ⌘ for a moment anywhere in diri to see shortcut hints on the controls. Every shortcut can be changed in Settings → Shortcuts.
