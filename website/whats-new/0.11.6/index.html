diri 0.11.6: App Skills for computer use

diri 0.11.6 lets computer use learn a Mac app task once and replay it without a model, keeps pinned projects in the sidebar, and cuts interruptions.

App Skills

An agent learns a task in a Mac app once and replays it later with new arguments, with no model in the loop. A broken step is reported so the agent can fix the skill.

Foreground actions

When background input can't reach a file picker or system dialog, an agent can bring the window forward for one action. Off by default; choose Ask each session or Always in Settings.

Pinned projects stay put

A pinned project keeps its place in the sidebar after its last session closes, so closing every agent no longer erases your layout.

Fewer interruptions

Closing a session no longer asks first, toasts that confirmed what you just did are gone, and ⌘T starts a session directly.

Skill usage

Settings › Skills shows how often each skill runs, which you use most, and which you never use.

And more

⌘K finds sessions in collapsed projects, notes show pictures linked by web address, and the sidebar stays smooth in an unfocused window.

Every fix and smaller change is in the full release notes. diri updates itself; this release shows up as a restart prompt when it is ready.
