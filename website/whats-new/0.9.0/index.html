diri 0.9.0: Notes, and to-dos that start agents

diri 0.9.0 adds Notes: plans and to-do lists that sit next to your agents, where any to-do can start an agent with the note as its brief.

Notes

Think next to your agents. Type / for blocks and @ to link a session; every note is plain Markdown on disk.

To-dos that start agents

Press ⌃⌘↩ on a to-do to hand it to an agent with the note as context. Its progress shows up right under the to-do.

Search every note

⇧⌘F finds a note by anything it says, not just its title.

Every fix and smaller change is in the full release notes. diri updates itself; this release shows up as a restart prompt when it is ready.
