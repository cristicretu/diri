diri 0.11.0: Scripting, splits you can read, and nothing lost under load

diri 0.11.0 adds Lua scripting, readable splits and terminal setup import, keeps every byte of a flood, and runs on a faster terminal core.

Script diri with Lua

An init.lua in ~/.config/diri adds keys, key modes, palette commands and event handlers, and reloads when you save. dirijor script runs one-off scripts.

Splits you can read at a glance

A split tab draws its layout in the sidebar and tab strip, each pane colored by what it's doing. Drag panes by their title to rearrange them.

See the question, keep the title

A waiting session keeps its name and shows its question on a second line.

Bring your terminal setup

Import font, theme and cursor from Ghostty, iTerm2, WezTerm, kitty, Alacritty or Terminal, with every change shown first.

Nothing lost, less waiting

Floods of output arrive complete, idle tabs cost nothing, Find searches all of history, and resizing keeps every line.

A faster terminal core

diri's terminal engine is rewritten and processes terminal text 3–4× faster.

Every fix and smaller change is in the full release notes. diri updates itself; this release shows up as a restart prompt when it is ready.
